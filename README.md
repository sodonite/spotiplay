# spotiplay
With this small but functional device, you can easily and intuitively control your Spotify music, with the ability to skip tracks, pause, add to favorites, choose the DJ, and adjust the volume using the built-in knob.
All of this using an ESP32 controller and a display that shows the actions to be performed, with everything connected according to the following schematic diagram
